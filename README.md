## 1. О проекте BizMind

**BizMind** — это специализированная цифровая B2B-система для малого бизнеса (в первую очередь небольших кофеен, кафе, пекарен и фастфуд-точек формата To-Go), объединяющая в одном окне:
1. **Управление финансами** (доходы, расходы, статьи затрат, кассовый результат, маржинальность).
2. **Каталог сырья и товаров** (SKU, единицы измерения, неснижаемые складские остатки).
3. **Реестр поставщиков и коммерческих предложений** (условия доставки, минимальные партии, отслеживание истории цен).
4. **Управление закупками и заказами** (жизненный цикл заказа от черновика до приемки с печатным бланком накладной).
5. **Складской учет и движения** (оприходование при приемке, инвентаризация, списания брака, журнал движений).
6. **Сравнение цен поставщиков** (нормализация к общей единице измерения, учет затрат на доставку и предупреждение об устаревших прайс-листах).
7. **Аналитический дашборд** (динамические расчеты на основе базы данных, визуализация динамики и категорий затрат).
8. **Статистическое прогнозирование** (расчет среднесуточного расхода, оценка дней до исчерпания и честная обработка нехватки данных).
9. **Центр уведомлений** (сигналы по реальным бизнес-правилам: скачки цен, дефицит, неразобранные заказы).
10. **Модуль импорта и экспорта** (генераторы шаблонов `.xlsx`/`.csv`, валидация строк с номерами ошибок, дедупликация и выгрузка отчетов).
11. **Ролевой доступ (RBAC) и аудит** (роли Owner, Manager, Employee, криптографическое хеширование паролей, неизменяемый системный журнал действий).
12. **Мультитенантная изоляция** (независимые пространства «Cafe Aroma» и «Daily Cup»).

Система разработана для автономной работы без обязательного наличия платных внешних API: пользователи могут работать с данными через интерфейс либо загружать таблицы Excel/CSV.

## 2. Архитектура и стек технологий

```
┌────────────────────────────────────────────────────────────────────────┐
│                          Пользователь (Браузер)                        │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ HTTP / REST / X-Organization-Id
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Nginx (Порт 80)                                │
│   • Раздача SPA (React 19 + TypeScript + Vite)                        │
│   • Reverse Proxy: /api/* -> FastAPI Backend                          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     FastAPI Backend (Порт 8000)                        │
│   • API Routers (auth, finances, products, orders, inventory, etc.)    │
│   • Security & RBAC (PBKDF2-HMAC-SHA256, Owner/Manager/Employee)       │
│   • Service Layer (OrderService, InventoryService, Comparison, etc.)   │
│   • Auto-Migrations & Integrity (SQLite Pragmas, Foreign Keys)         │
│   • Import/Export Engine (openpyxl, pandas)                            │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   SQLite 3 Database (bizmind.db)                       │
│   • Multi-Tenant Isolation (organization_id)                          │
│   • 12 таблиц со строгими связями и внешними ключами                   │
│   • Persistent Volume в Docker                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### Технологический стек:
* **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS, Recharts (графики), Lucide-react (иконки), Axios.
* **Backend:** FastAPI, Python 3.12, SQLAlchemy 2.0, Pydantic v2, OpenPyXL, Pandas, Uvicorn.
* **База данных:** SQLite 3 с поддержкой внешних ключей (`PRAGMA foreign_keys = ON`) и механизмом авто-миграций структуры.
* **Тестирование:** Pytest (18 автоматических тестов), `tsc -b` (статическая типизация).
* **Контейнеризация:** Docker, Multi-stage builds, Docker Compose, Nginx Alpine.

## 3. Быстрый запуск

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что установлены `docker` и `docker compose`:

```bash
# 1. Клонирование или переход в каталог проекта
cd BizMind

# 2. Переключение на рабочую ветку учебного MVP
git checkout feature/educational-mvp

# 3. Запуск контейнеров (сборка backend и frontend)
docker compose up -d --build

# 4. Проверка статуса контейнеров
docker compose ps
```

Приложение доступно по адресу: **`http://localhost`**  
Документация Swagger API доступна по адресу: **`http://localhost:8000/docs`** (или через прокси `http://localhost/api/docs`).

Остановка контейнеров:
```bash
docker compose down
```
*(База данных сохраняется в именованном томе `bizmind_db_data`)*.

---

### Вариант 2: Локальный запуск для разработки

#### Требования:
* Python 3.12+ (рекомендуется пакетный менеджер `uv`)
* Node.js 20+ и `npm`

#### Шаг 1: Запуск Backend
```bash
cd backend

# Установка зависимостей через uv
uv sync

# Запуск сервера разработки FastAPI
uv run uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

#### Шаг 2: Запуск Frontend
В отдельном окне терминала:
```bash
cd frontend

# Установка зависимостей
npm install

# Запуск Vite Dev Server
npm run dev
```

Приложение откроется по адресу: **`http://localhost:5173`**.
