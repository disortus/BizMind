## 1. О проекте BizMind

**BizMind** — это специализированная цифровая B2B-система для малого бизнеса (кофейни, кафе, пекарни и фастфуд To-Go), объединяющая в едином окне:

1. **Каталог товаров и номенклатура:** ведение номенклатурных карточек (SKU, базовые единицы измерения, неснижаемые страховые запасы).
2. **Общий маркетплейс поставщиков:** проверенный глобальный каталог проверенных поставщиков г. Астана и Казахстана с условиями доставки, минимальным заказом (MOA) и клеймом происхождения (`source_type = 'global'`).
3. **Оформление заказов по каталогу (Catalog Price Locking):** выбор поставщика, автоматическая загрузка его позиций, жесткая фиксация цен, валидация минимальной партии (MOQ) и суммы (MOA).
4. **Управление черновиками и накладными:** создание черновиков, редактирование позиций и объемов до отправки, генерация печатных товарных накладных.
5. **Складской партионный учет:** оприходование при приемке заказов, инвентаризация, списания брака с фиксацией причин, неизменяемый журнал движений (`inventory_movements`), экспорт остатков в Excel (`.xlsx`) и CSV.
6. **Сравнение цен поставщиков:** матрица предложений с интерактивным выбором любой альтернативной карточки, нормализацией к единице и прозрачным расчетом экономии с учетом платной логистики.
7. **Конструктор отчётов (Report Builder):** 4 системных пресета, создание кастомных шаблонов, интерактивный предпросмотр KPI, диаграмм и детальных таблиц с выгрузкой в форматированный Excel (`.xlsx`) и CSV.
8. **Управление финансами (ДДС):** журнал доходов и расходов, статьи затрат, кассовое сальдо, исключение повторного списания за счет маркировки `purchase_order_id`.
9. **Два сквозных сценария внедрения**:
   - **Cafe Aroma:** чистое состояние нового заведения (0 фиктивных операций, интерактивный онбординг-роадмап, пошаговая загрузка файлов).
   - **Daily Cup:** 6 месяцев зрелой эксплуатации с подтвержденной реализованной экономией **450 000+ ₸**.
10. **Аналитический дашборд:** динамические расчеты на лету из SQLite/Postgres без статических заглушек.
11. **Статистическое прогнозирование:** расчет среднесуточного расхода, оценка дней до исчерпания и честный статус `insufficient_data` при нехватке истории.
12. **Центр уведомлений:** алерты о скачках цен, дефиците сырья и зависших черновиках с кнопками быстрого перехода к решению.
13. **Безопасность, сотрудники и аудит:** роли Owner, Manager, Employee, PBKDF2-HMAC-SHA256 хеширование паролей, встроенный генератор надежных паролей с переключателем видимости («глазок»), неизменяемый журнал аудита действий (`activity_logs`).
14. **Мобильная адаптивность (Mobile UX):** плавный выдвижной Drawer сайдбара, адаптивные таблицы с горизонтальным скроллом и адаптация модальных окон при экранной клавиатуре.

## 2. Архитектура и стек технологий

```
┌────────────────────────────────────────────────────────────────────────┐
│                          Пользователь (Браузер)                        │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ HTTP / REST / X-Organization-Id
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        Nginx (Порт 80)                                │
│   • Раздача SPA (React 19 + TypeScript + Vite)                        │
│   • Reverse Proxy: /api/* -> FastAPI Backend                          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     FastAPI Backend (Порт 8000)                        │
│   • 14 API-роутеров (auth, finances, products, orders, reports, etc.)  │
│   • Security & RBAC (PBKDF2-HMAC-SHA256, Owner/Manager/Employee)       │
│   • Service Layer (OrderService, InventoryService, ReportService...)   │
│   • Zero-Downtime Auto-Migrations (SQLite Pragmas, Foreign Keys)       │
│   • Import/Export Engine (openpyxl, pandas)                            │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   SQLite 3 Database (bizmind.db)                       │
│   • Multi-Tenant Row-Level Isolation (organization_id)                 │
│   • 15 таблиц со строгими связями и внешними ключами                   │
│   • Именованный том Docker (bizmind_db_data:/app/data)                 │
└────────────────────────────────────────────────────────────────────────┘
```

### Технологический стек:
* **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS, Recharts (графики), Lucide-react (иконки), Axios.
* **Backend:** FastAPI, Python 3.12, SQLAlchemy 2.0, Pydantic v2, OpenPyXL, Pandas, Uvicorn.
* **База данных:** SQLite 3 с поддержкой внешних ключей (`PRAGMA foreign_keys = ON`) и авто-миграциями схемы / PostgreSQL через `DATABASE_URL`.
* **Тестирование:** Pytest (36 автоматических тестов), `tsc -b` (100% покрытие типов).
* **Контейнеризация:** Docker, Multi-stage builds, Docker Compose, Nginx Alpine.

## 3. Быстрый запуск

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

```bash
# 1. Переход в каталог проекта
cd BizMind

# 2. Запуск контейнеров (сборка backend и frontend)
docker compose up -d --build

# 3. Проверка статуса контейнеров
docker compose ps
```

Приложение доступно по адресу: **`http://localhost`**  
Интерактивная документация Swagger API: **`http://localhost:8000/docs`** (или `http://localhost/api/docs`).

Остановка контейнеров:
```bash
docker compose down
```
*(База данных надежно сохраняется в томе `bizmind_db_data`)*.

---

### Вариант 2: Локальный запуск для разработки

#### Шаг 1: Запуск Backend
```bash
cd backend
uv sync
uv run uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```

#### Шаг 2: Запуск Frontend
В отдельном терминале:
```bash
cd frontend
npm install
npm run dev
```
Приложение откроется по адресу: **`http://localhost:5173`**.
