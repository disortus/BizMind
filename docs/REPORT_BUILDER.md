# Модуль конструктора отчётов (Report Builder) в BizMind

## 1. Назначение и концепция

Модуль **«Шаблонизатор отчётов»** — это встроенный аналитический инструмент BizMind, позволяющий владельцам и управляющим малого бизнеса (кофейни, пекарни, кафе):
1. **Формировать кастомизированные аналитические срезы** за произвольный или предопределенный период (текущий месяц, прошлый месяц, квартал, полугодие, год).
2. **Выбирать интересующие разделы и метрики** без необходимости ручного сведения таблиц в Excel.
3. **Группировать данные** по дням, неделям, месяцам, товарным категориям или поставщикам.
4. **Сохранять конфигурации в виде шаблонов** для регулярного повторного использования (еженедельные планёрки, ежемесячное закрытие периода).
5. **Просматривать интерактивный предпросмотр** прямо в браузере (сводные карточки KPI, интерактивные графики распределения, детальная таблица).
6. **Экспортировать результат** в профессионально оформленный файл **Excel (`.xlsx`)** со стилями, рамками, авто-шириной колонок и формулами, а также в формат **CSV** для интеграции с внешними системами.

## 2. Архитектура и безопасность

### 2.1. Мультитенантность и изоляция данных
- Шаблоны отчетов строго привязаны к организации (`organization_id`).
- Организация не может просматривать, изменять или удалять шаблоны других организаций.
- **Глобальные системные пресеты** (`is_system = True`, `organization_id = None`) доступны всем пользователям только для чтения и запуска. Пользователь может создать независимую копию системного шаблона (`POST /api/reports/templates/{id}/duplicate`), которая станет локальным шаблоном его организации.

### 2.2. Защита от инъекций (No-SQL Injection by Design)
- Конфигурация шаблона хранится в формате JSON и валидируется схемой Pydantic (`ReportTemplateConfig`).
- Сервер **не выполняет произвольный SQL-код или скрипты**. Все расчеты производятся детерминированными методами сервисного слоя (`ReportService`) на основе строго типизированных запросов SQLAlchemy.
- Все параметры периода (`period_type`, `date_from`, `date_to`), группировок (`group_by`) и типов отчетов (`report_type`) ограничены фиксированными перечислениями.

## 3. Модель данных

Таблица `report_templates`:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `INTEGER PRIMARY KEY` | Уникальный идентификатор шаблона |
| `organization_id` | `INTEGER NULL` | ID организации (NULL для системных шаблонов) |
| `title` | `VARCHAR(255)` | Название шаблона |
| `description` | `TEXT NULL` | Понятное описание назначения отчёта |
| `report_type` | `VARCHAR(50)` | Тип отчёта: `financial`, `procurement`, `inventory`, `executive`, `savings` |
| `config` | `JSON` | Валидируемый JSON с настройками (период, разделы, фильтры, сортировка) |
| `is_system` | `BOOLEAN` | Флаг системного предустановленного шаблона |
| `is_archived` | `BOOLEAN` | Флаг архивации (мягкое скрытие) |
| `created_by_user_id` | `INTEGER NULL` | Автор шаблона |
| `created_at` | `DATETIME` | Дата и время создания |
| `updated_at` | `DATETIME` | Дата и время последнего изменения |

### 3.1. Структура конфигурации (`config`)
```json
{
  "period_type": "last_month", // "current_month", "last_month", "quarter", "year", "custom"
  "date_from": "2026-09-01",
  "date_to": "2026-09-30",
  "sections": ["kpi_summary", "chart", "details_table", "top_expenses"],
  "group_by": "category", // "category", "supplier", "month", "day"
  "sort_by": "amount",
  "sort_order": "desc",
  "include_charts": true,
  "filters": {
    "category": null,
    "supplier_id": null
  }
}
```

## 4. Предустановленные системные шаблоны

Система поставляется с 4 готовыми эталонными шаблонами:

1. **Ежемесячный финансовый отчёт** (`financial`)
   - Назначение: Комплексный анализ доходов, расходов, операционной прибыли и маржинальности за прошлый календарный месяц.
   - Включает: сводные KPI, долю категорий расходов, динамику по дням, реестр финансовых операций.

2. **Анализ закупок и изменения цен** (`procurement`)
   - Назначение: Контроль динамики закупочных цен, объёмов поставок по поставщикам и расчётной экономии.
   - Включает: суммарные затраты на закупку, распределение по поставщикам, динамику изменения цен сырья.

3. **Склад и критические остатки** (`inventory`)
   - Назначение: Мониторинг складских запасов, себестоимости хранения и выявление позиций с риском дефицита.
   - Включает: оценку складского остатка, количество критических SKU, рекомендации к пополнению.

4. **Сводный отчёт владельца кафе** (`executive`)
   - Назначение: Верхнеуровневый управленческий дашборд для собственника, объединяющий ключевые финансовые, закупочные и складские метрики за полугодие.
   - Включает: чистую прибыль, структуру постоянных и переменных затрат, топ контрагентов по затратам.

## 5. Формирование отчёта: предпросмотр и экспорт

### 5.1. Интерактивный предпросмотр (`POST /api/reports/preview`)
Позволяет протестировать параметры отчета без скачивания файла:
- **`kpi_summary`**: Ключевые показатели (выручка, расходы, прибыль, закупки, остатки, экономия).
- **`chart_data`**: Готовые данные для отрисовки графиков в Recharts (круговые диаграммы распределения, столбчатые диаграммы динамики).
- **`columns` & `rows`**: Табличная часть с типизированными значениями.
- **`notes`**: Пояснения к методике расчета и временным рамкам.

### 5.2. Экспорт в Microsoft Excel (`POST /api/reports/export/excel`)
Формирует файл `.xlsx` с использованием библиотеки `openpyxl`:
- Брендированная шапка BizMind с названием компании, периодом и датой генерации.
- Блок карточек ключевых показателей (KPI) с заливкой и выделением цветом.
- Форматированная таблица деталей: темно-синий заголовок (`#1E293B`), чередующиеся строки, границы ячеек.
- Числовой формат с разделением тысяч и суффиксом тенге (`₸`).
- Автоматический подбор оптимальной ширины колонок.

### 5.3. Экспорт в CSV (`POST /api/reports/export/csv`)
Формирует UTF-8 текстовый файл с разделителем «запятая», корректно открывающийся в любых табличных редакторах и системах учета (1С, Google Таблицы).

## 6. Примеры API-запросов

### Получение списка доступных шаблонов:
```http
GET /api/reports/templates
Authorization: Bearer <token>
X-Organization-Id: 2
```

### Генерация интерактивного предпросмотра:
```http
POST /api/reports/preview
Content-Type: application/json
Authorization: Bearer <token>
X-Organization-Id: 2

{
  "report_type": "financial",
  "config": {
    "period_type": "last_month",
    "group_by": "category",
    "sort_by": "amount",
    "sort_order": "desc"
  }
}
```

### Скачивание Excel-файла:
```http
POST /api/reports/export/excel
Content-Type: application/json
Authorization: Bearer <token>
X-Organization-Id: 2

{
  "report_type": "executive",
  "config": {
    "period_type": "year"
  }
}
```
Ответ: двоичный поток `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.
