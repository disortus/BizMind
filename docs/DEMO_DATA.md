## 2. Сценарий A: Cafe Aroma — первичное внедрение и чистый старт

### 2.1. Описание организации
«Cafe Aroma» — кофейня в г. Астана, ранее ведущая учёт в разнородных таблицах Excel. На момент первого входа в BizMind система находится в эталонном чистом состоянии:
* **Финансы:** 0 транзакций, доходы и расходы равны `0 ₸`.
* **Закупки:** 0 фактических поставок.
* **Склад:** номенклатурные карточки созданы, но фактический остаток равен `0`.
* **Прогнозирование:** статус `insufficient_data` («Недостаточно данных для построения расхода и прогноза запасов»).
* **Алерты:** 0 ложных алертов о скачках цен.
* **Дашборд:** активирует режим **интерактивного онбординга (Progressive Roadmap)** с карточками 4 этапов загрузки данных.

### 2.2. Пакет файлов для поэтапного онбординга
Файлы для демонстрации загрузки подготовлены в папке [`demo_data/onboarding/cafe_aroma/`](file:///home/disortus/coop-projs/BizMind/demo_data/onboarding/cafe_aroma/):

1. **`historical_finances.xlsx`** (53 операции)
   - Реальные доходы кассы и операционные расходы на аренду, коммуналку, ФОТ и хозтовары за лето 2026 г.
2. **`supplier_price_lists.xlsx`** (10 позиций прайсов)
   - Предложения поставщиков с ценами за единицу, квантами закупки (MOQ) и стоимостью доставки.
3. **`historical_inventory.xlsx`** (10 складских позиций)
   - Начальные складские остатки: зерно, сиропы, молоко, упаковка, расходники.
4. **`historical_purchases.xlsx`** (31 закупка)
   - Фактические поставки за последние месяцы для обучения алгоритма среднедневного расхода.

## 3. Сценарий B: Daily Cup — 6 месяцев регулярного использования и экономия

### 3.1. Описание организации
«Daily Cup» — заведение, использующее BizMind с мая по октябрь 2026 года. Накопленная история демонстрирует реальный финансовый эффект внедрения контроля закупок.

### 3.2. Математика подтвержденной экономии (Realized Savings)
В отличие от гипотетических прогнозов, реализованная экономия рассчитывается по формуле:
$$\text{Savings} = \sum (\text{BasePrice} - \text{PurchasedPrice}) \times \text{Quantity}$$

1. **Бумажные стаканы 250 мл (Одноразовая посуда)**
   - Прежняя цена закупки: **28 ₸ / шт.**
   - Цена по контракту с EcoDisposables KZ: **19 ₸ / шт.** (экономия **9 ₸ / шт.**).
   - Закуплено за 6 месяцев: **12 000 шт.**
   - Экономия: $12\,000 \times 9 = \mathbf{108\,000\text{ ₸}}$.
2. **Кофе в зернах Espresso Blend 100% Arabica**
   - Прежняя цена закупки: **7 200 ₸ / кг.**
   - Согласованная цена ТОО "SilkWay Coffee Roasters": **5 800 ₸ / кг.** (экономия **1 400 ₸ / кг.**).
   - Закуплено: **150 кг.**
   - Экономия: $150 \times 1\,400 = \mathbf{210\,000\text{ ₸}}$.
3. **Молоко ультрапастеризованное 3.2%**
   - Прежняя цена: **540 ₸ / л.**
   - Цена Qazaq Dairy: **460 ₸ / л.** (экономия **80 ₸ / л.**).
   - Закуплено: **1 800 л.**
   - Экономия: $1\,800 \times 80 = \mathbf{144\,000\text{ ₸}}$.

**ИТОГО ПОДТВЕРЖДЕННАЯ ЭКОНОМИЯ:** **462 000 ₸**.

## 5. Системные пресеты конструктора отчетов

В систему предзагружены 4 системных шаблона отчетов (`is_system = True`):

1. **Ежемесячный финансовый отчёт** (`report_type: financial`)
   - KPI выручки, операционных расходов, чистой прибыли.
   - Разбивка затрат по категориям и динамика за период.
2. **Анализ закупок и изменения цен** (`report_type: procurement`)
   - Реестр поставок, динамика закупочных цен, подтвержденная экономия по контрагентам.
3. **Склад и критические остатки** (`report_type: inventory`)
   - Ведомость остатков, оценка стоимости запасов, позиции ниже страхового минимума.
4. **Сводный отчёт владельца кафе (Executive Summary)** (`report_type: executive`)
   - Комплексная управленческая сводка для руководства со всеми ключевыми метриками.

## 6. Воспроизводимость данных и сброс состояния (Seed Scripts)

### Сброс через веб-интерфейс или API:
Отправьте POST-запрос на эндпоинт сброса:
```bash
curl -X POST http://localhost:8000/api/demo/reset
```

### Сброс через CLI:
```bash
cd backend
uv run python -m backend.demo.seed_data
```

Скрипт полностью идемпотентен, очищает базу SQLite и заново накатывает эталонное состояние обеих кофейных организаций и системных справочников.
