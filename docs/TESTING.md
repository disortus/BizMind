## 5. Известные ограничения и непроверенные сценарии

1. **Внешние API поставщиков:**
   - В текущем MVP интеграция с реальными внешними API (1С, МойСклад, EDI) не реализуется нарочно в соответствии с ТЗ. Обмен прайсами осуществляется через Excel/CSV и встроенный каталог.
2. **Анализ списаний с рецептурными картами (технологические карты):**
   - Автоматическое списание граммов кофе на каждую проданную чашку эспрессо (кассовая интеграция с фискальным регистратором) в учебном MVP моделируется через периодические инвентаризации и ручные складские движения.
3. **Хранилище SQLite в многопользовательском режиме:**
   - SQLite с `PRAGMA foreign_keys=ON` обеспечивает надежную работу локально и в Docker-контейнере. Для масштабирования на сотни одновременных распределенных пользователей предусмотрена поддержка PostgreSQL через `DATABASE_URL`.
