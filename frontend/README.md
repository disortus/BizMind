## 1. Обзор приложения

Фронтенд BizMind — это одностраничное веб-приложение (SPA), разработанное для оперативной аналитики и управления закупками предприятий малого бизнеса (кофейни, кафе, пекарни):
* **Закупки и поставщики:** оформление заказов с блокировкой цен по официальному каталогу поставщика, проверка квантов закупки (MOQ) и минимального заказа (MOA).
* **Складской учет:** контроль остатков номенклатуры, оприходование поставок, списания брака, инвентаризация и экспорт ведомостей в Excel (`.xlsx`).
* **Аналитическое сопоставление:** матрица сравнения цен альтернативных поставщиков с возможностью выбора любой карточки и гибким калькулятором партии.
* **Конструктор отчетов (Report Builder):** 4 системных пресета, создание кастомных шаблонов, интерактивный предпросмотр KPI и графиков, выгрузка в стилизованный Excel и CSV.
* **Финансы и ДДС:** журнал доходов и расходов, аналитика структуры затрат и маржинальности.
* **Безопасность и сотрудники:** управление командой, ролевой доступ (Owner, Manager, Employee), встроенный генератор криптостойких паролей и переключатель видимости («глазок»).
* **Онбординг и сценарии A/B:** пошаговый путеводитель первого запуска для «Cafe Aroma» и зрелая 6-месячная аналитика с подтвержденной экономией 450 000+ ₸ для «Daily Cup».

## 3. Ключевые механизмы и состояние

### 3.1. Мультитенантность и сохранение сессии (`api.ts`)
* Идентификатор активной организации сохраняется в `localStorage` по ключу `bizmind_org_id`.
* Axios Request Interceptor автоматически подставляет заголовок `X-Organization-Id` в каждый запрос.
* Метод `api.logout()` очищает сессию и переводит пользователя на экран выбора демонстрационного сценария.

### 3.2. Отказоустойчивость (`ErrorBoundary.tsx`)
Корневой компонент `<App />` обернут в `ErrorBoundary`. При возникновении исключения рендера пользователь видит понятный интерфейс с диагностической информацией и кнопками мгновенного восстановления без потери данных.

## 4. Разделы и функциональность страниц

### 4.1. Сводный дашборд (`DashboardPage.tsx`)
* **KPI сводка:** Выручка, Расходы, Чистый баланс, Реализованная экономия.
* **Онбординг-роадмап для пустой организации:** Пошаговые карточки 4 этапов загрузки исторических файлов для Cafe Aroma.
* **Инфляционный баннер:** Предупреждение о скачках цен с кнопкой прямого перехода в модуль сравнения.
* **Графики Recharts:** Динамика доходов/расходов и круговая диаграмма долей затрат.

### 4.2. Заказы на поставку (`OrdersPage.tsx`)
* **Выбор поставщика:** При оформлении заказа в первую очередь выбирается контрагент.
* **Каталог товаров поставщика:** Загружаются только доступные товары с заблокированными ценами (`catalog price locking`) — ручной ввод произвольных цен исключен.
* **Валидация MOQ и MOA:** Проверяется минимальный квант закупки по каждой позиции и минимальная сумма заказа поставщика.
* **Редактирование черновиков:** Доступно изменение количеств и номенклатуры в статусе `draft`.
* **Печатные накладные:** Генерация форматированного бланка для отправки поставщику.
* **Приемка на склад:** Кнопка «Принять на склад» оприходует сырье и фиксирует расход в финансах.

### 4.3. Склад и остатки (`InventoryPage.tsx`)
* Текущие складские остатки со статусами (`В норме`, `Критический остаток`, `Исчерпано`).
* Операции инвентаризации (корректировка остатка) и списания брака с фиксацией причин.
* Журнал складских движений (`inventory_movements`).
* **Экспорт ведомости в Excel (.xlsx):** Работает стабильно как на заполненной, так и на пустой базе.

### 4.4. Сравнение предложений поставщиков (`ComparisonPage.tsx`)
* Матрица всех предложений поставщиков с карточками контрагентов.
* **Интерактивный выбор любой альтернативной карточки:** Пользователь может кликнуть на любого поставщика, и калькулятор мгновенно рассчитает выгоду для выбранной позиции.
* Автоматический учет стоимости платной доставки и минимальной партии.

### 4.5. Конструктор отчетов (`ReportsPage.tsx`)
* Библиотека системных пресетов: Ежемесячный финансовый отчёт, Анализ закупок, Складской аудит, Executive Summary.
* Создание пользовательских шаблонов с фильтрацией по периодам, группировкам и колонкам.
* Интерактивный предпросмотр в реальном времени.
* Экспорт в профессионально стилизованный Excel (`.xlsx`) и CSV.

### 4.6. Настройки и команда (`SettingsPage.tsx`)
* Профиль организации: адрес, телефон, валюта, порог алертов.
* **Управление сотрудниками:** Добавление пользователей с ролями (Owner, Manager, Employee).
* **Генератор паролей:** Кнопка автоматической генерации криптостойкого пароля.
* **Переключатель видимости пароля:** Иконка «глазка» для отображения/маскирования пароля при вводе.
* **Журнал аудита действий (Activity Log):** Неизменяемый журнал всех системных операций.

## 5. Адаптивность и мобильный интерфейс (Mobile UX)

* **Мобильная шторка (Drawer Navigation):** На экранах `< lg` стационарный сайдбар заменяется на выдвижную шторку с полупрозрачным блюр-фоном и кнопкой закрытия. Меню автоматически сворачивается при клике на ссылку.
* **Адаптивные таблицы (Touch Tables):** Все таблицы обернуты в скролл-контейнеры с сохранением отступов на узких дисплеях.
* **Модальные окна с защитой от экранной клавиатуры:** Окна имеют `max-h-[92dvh] overflow-y-auto`, предотвращая скрытие полей ввода.

## 6. Запуск и сборка

### Локальная разработка:
```bash
cd frontend
npm install
npm run dev
```
Сервер запустится по адресу: `http://localhost:5173`.

### Сборка продакшен-бандла:
```bash
npm run build
```
Выполняется проверка типов TypeScript (`tsc -b`) и компиляция через Vite в папку `dist/`.

### Проверка типов без сборки:
```bash
npx tsc -b
```
Сборка проходит со **100% успехом (0 ошибок типизации)**.
